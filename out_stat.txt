    A generic plugin for Open Journal Systems 3.5+ that extends the OJS API to generate dummy users, submissions, and issues for development and testing environments.
    
    ### Overview
    This plugin adds custom routes to the existing `/api/v1/users` endpoint and uses OJS internal services to create and manage test data.
    It is designed for developers, journal administrators, and system testers who need reproducible data for workflow validation.
    **Important:**
    All endpoints are implemented by this plugin and are not part of the core OJS API.
    ---
    ### Features
    * Generate dummy users with Author role
    * Generate submissions with metadata and placeholder files
    * Programmatically apply editorial decisions to simulate workflow progression
    * Create and publish issues with generated submissions
    * Track generated entities for safe and reversible cleanup
    ---
    ### API Endpoints
    All endpoints extend the OJS users API:
    ```
    POST   /api/v1/users/generate-users
    POST   /api/v1/users/generate-submissions
    POST   /api/v1/users/generate-issue
    DELETE /api/v1/users/cleanup
    ```
    Authentication and authorization are handled by the OJS API layer.
    ---
    ### Requirements
    * OJS 3.5.x
    * PHP 8.2+
    * Journal Manager or Site Administrator role
    ---
    ### Installation
    1. Copy plugin to:
    ```
    plugins/generic/dummyDataGenerator
    ```
    2. Clear cache
    3. Enable via Website Administration → Plugins
    ---
    ### Typical Usage
    ```
    generate-users → generate-submissions → generate-issue → cleanup
    ```
    ---
    ### Notes
    * Intended for development and testing environments
    * Workflow actions are simulated via programmatic decision application
    * Generated data is tracked and can be safely removed using the cleanup endpoint
